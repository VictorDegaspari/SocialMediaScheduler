Perguntas frequentes

Preciso conectar o Google Drive?

Somente se ele for a origem escolhida. Pastas locais funcionam sem essa conexão. As contas de destino ainda precisam ser autorizadas para que haja envio.

O aplicativo funciona com o computador desligado?

Não. A instalação local precisa do computador e dos serviços ativos. Fechar o navegador não interrompe a rotina; desligar ou suspender a máquina, sim.

O TikTok publica automaticamente?

O fluxo atual exige revisão e autorização individual para transferir o vídeo à caixa de entrada. Depois, você conclui a publicação no aplicativo TikTok. A integração depende dos escopos liberados pelo provedor.

Por que o vídeo do YouTube está privado?

Essa é a configuração padrão. Confira o campo de visibilidade no JSON e as restrições do projeto Google. Confira também as permissões da conta, a configuração do projeto Google e o resultado exibido no YouTube Studio.

O Google bloqueou o acesso durante a autorização.

Se o aplicativo OAuth estiver em testes, a conta precisa estar cadastrada como usuário de teste no projeto Google. O proprietário do projeto deve conferir público, escopos e a URI exata de retorno. Nunca compartilhe o segredo do cliente em uma captura.

O site precisa de HTTPS se o aplicativo é local?

O site público solicitado pelo portal TikTok precisa ser um endereço HTTPS acessível. O callback de Login Kit Desktop é outro endereço: pode usar localhost com porta, conforme a configuração aceita pelo TikTok. O site de apresentação não recebe o callback da instalação local.

Remover metadados elimina a declaração de IA?

Não. A opção limpa tags descritivas de uma cópia do arquivo. Não garante ausência de identificação de IA e não substitui as declarações exigidas por YouTube ou TikTok.

O site já permite criar uma conta e publicar?

Este site contém apresentação, documentação, contato e políticas. O aplicativo atual é de instalação própria, com uma conta por plataforma em cada instalação. Para orientações de uso e disponibilidade, entre em contato.

Como interromper uma rotina ou excluir meus dados?

Pause as rotinas no painel, desconecte as contas e revogue as permissões nos provedores. Para apagar o histórico e as cópias locais, siga a página de exclusão de dados. Desconectar não apaga publicações nas plataformas.
