VOCÊ DECIDE QUANDO PARAR

Conexões e dados sob seu controle.

Pausar o processamento, revogar uma permissão e apagar dados são ações diferentes. Siga as orientações conforme o que você deseja remover.

1. Interrompa os novos envios

Abra o painel da instalação e pause as rotinas. Se houver envios em andamento ou aguardando revisão, confira o histórico antes de continuar. Pausar uma rotina não remove os dados já armazenados ou transferidos.

2. Desconecte a conta no painel

Na aba Conexões, use a opção de desconectar o serviço desejado. Isso remove os tokens locais daquela conexão e, nas integrações sociais, a identificação local da conta. Credenciais do cliente OAuth, rotinas, histórico e cópias em revisão podem continuar armazenados.

A desconexão não revoga automaticamente o consentimento no provedor e não exclui vídeos publicados. Para encerrar também a autorização externa, faça a etapa seguinte.

3. Revogue o acesso no provedor

  • Google Drive e YouTube: acesse as configurações de permissões da Conta Google, encontre o aplicativo autorizado e remova o acesso.
  • TikTok: nas configurações de segurança e permissões da conta, localize os aplicativos conectados e remova a autorização correspondente.
  • Postiz opcional: revogue a chave e as conexões na instalação Postiz administrada por você, se essa alternativa foi configurada.

Se uma mesma autorização Google cobrir mais de um recurso, a remoção pode interromper todas as conexões associadas. Reconecte apenas os serviços que pretende continuar usando.

4. Solicite a exclusão dos dados armazenados

Para dados de uma instalação ou atendimento administrados por Victor Degaspari, envie um e-mail para eshoputilities@gmail.com com o assunto Exclusão de dados — SocialMediaScheduler.

  • Identifique a conta ou o canal relacionado e a instalação, se souber.
  • Indique se deseja excluir uma conexão específica ou todos os dados administrados pelo responsável.
  • Informe um contato para confirmar a solicitação.

Não envie senhas, client secrets, tokens ou vídeos sensíveis no primeiro contato. Podemos pedir confirmação de identidade proporcional ao pedido. Solicitações de exclusão de dados armazenados da integração YouTube devem ser concluídas o quanto antes, em até 7 dias corridos.

Em uma instalação própria, o administrador local controla os dados. O responsável por este site não tem acesso remoto automático para apagá-los. Encaminhe a solicitação ao administrador ou execute a remoção no ambiente que você controla.

5. Para quem administra a instalação

A versão atual não tem um botão de exclusão completa. O administrador deve interromper os trabalhos relacionados, remover as credenciais e os registros correspondentes do banco, limpar os trabalhos pendentes e as cópias de mídia em revisão, e considerar logs e backups sob sua responsabilidade. A deduplicação e o histórico podem deixar de existir para os dados removidos.

Não apague arquivos originais do Drive ou do computador como parte de uma simples desconexão. Se estiver removendo toda a instalação, faça isso conscientemente: os volumes podem conter dados de outras rotinas. Consulte o responsável pelo ambiente para uma remoção direcionada.

6. Dados já enviados às plataformas

A remoção na aplicação não apaga vídeos, rascunhos ou outros dados já mantidos no YouTube, TikTok ou Google Drive. Use as ferramentas de cada serviço para excluir esses conteúdos. Para dúvidas sobre os dados efetivamente tratados, consulte a política de privacidade ou entre em contato.
